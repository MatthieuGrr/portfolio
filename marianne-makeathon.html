Marianne - Robot UGV Vainqueur

1ère place au Makeathon ARES 2025 (EDA)

Mai 2025
Cracovie, Pologne
Équipe French Touch

Le défi

Le Makeathon ARES 2025, organisé par l'Agence européenne de défense (EDA) à Cracovie, réunissait les meilleures équipes européennes autour d'un défi ambitieux : concevoir, fabriquer et programmer un robot UGV (Unmanned Ground Vehicle) autonome en quelques jours.

Le robot devait accomplir trois missions complexes en conditions réelles sur terrain accidenté. L'équipe French Touch a relevé ce défi avec Marianne, un robot de 48kg remportant la première place.

Les trois missions du défi

  • Task 1 - Logistique automatisée : Transporter et distribuer automatiquement 4 caisses depuis un point de chargement vers 4 points de livraison différents. Nécessite navigation précise, système de chargement/déchargement automatique et robustesse mécanique.
  • Task 2 - Reconnaissance terrain : Explorer une zone inconnue, créer une cartographie en temps réel et identifier des points d'intérêt. Requiert vision par ordinateur, SLAM (Simultaneous Localization and Mapping) et navigation autonome.
  • Task 3 - Détection NBC : Localiser et identifier des sources de contamination Nucléaire, Biologique ou Chimique à l'aide de capteurs spécialisés. Demande intégration de capteurs sensibles et traitement de données en temps réel.

Résultats

  • 🥇 1ère place toutes catégories
  • ✅ Tous les checkpoints validés
  • 🎯 Stratégie adaptative : mode téléopéré privilégié face au terrain difficile
  • ⚡ Système entièrement fonctionnel et robuste

Défis techniques

Défis relevés durant le Makeathon

  • Contrainte de temps : Conception, fabrication PCB, assemblage et test en 2 mois
  • Intégration multi-systèmes : Faire communiquer ROS2, CAN Bus, vision IA et contrôle moteurs
  • Débogage terrain : Adaptation rapide aux conditions réelles (terrain, interférences)
  • Gestion de l'énergie : Alimenter 4x1000W + électronique embarquée avec autonomie suffisante
  • Fiabilité mécanique : Le système de loader devait fonctionner parfaitement à chaque fois
  • Coordination d'équipe : Travail simultané sur mécanique, électronique et software

Conception mécanique

L'ensemble du robot a été conçu en CAO (Conception Assistée par Ordinateur) pour optimiser l'intégration des composants, la distribution de masse et l'accessibilité pour la maintenance.

Points clés de la conception

  • Structure modulaire : Facilite l'assemblage et les modifications rapides
  • Optimisation de masse : 48kg répartis de manière équilibrée sur les 4 roues
  • Protection des composants : Boîtiers étanches pour l'électronique sensible
  • Accessibilité : Compartiments facilement ouverts pour debug et réparations
  • Système de loader amovible : 4 tiroirs motorisés pour la distribution automatique
  • Capteurs NRBC optionnels en façade : Facilité d'ajout de capteurs grâce au CAN

Architecture électronique

PCB custom pour le système de chargement

Un PCB dédié a été conçu sur KiCad pour gérer le système de loader automatique à 4 tiroirs. Ce système constitue le cœur de la mission logistique, permettant la distribution automatique des caisses aux points de livraison.

Composants du PCB Loader

  • Microcontrôleur ESP32 : Cœur du système, gestion de la logique et communication
  • 2x DRV8825 : Drivers pour moteurs pas-à-pas avec microstepping
  • 2x NEMA17 : Moteurs pas-à-pas pour déploiement précis des tiroirs
  • Limit switches : Détection des positions initiale et finale de chaque tiroir
  • Transceiver CAN TJA1050 : Interface vers le bus CAN principal
  • Régulation de puissance : Alimentation stabilisée pour l'ESP32 et drivers
  • Protection : Circuits de protection contre les courts-circuits et surtensions

Fonctionnement

Chaque tiroir peut être déployé indépendamment via des commandes CAN. L'ESP32 reçoit les ordres depuis le système ROS2, contrôle les moteurs via les DRV8825, vérifie les positions avec les limit switches et remonte son état pour garantir un déploiement fiable et reproductible.

Architecture CAN Bus distribuée

Le robot utilise une architecture distribuée basée sur le protocole CAN Bus, offrant robustesse, latence faible et fiabilité même en environnement perturbé.

Nœuds sur le bus principal

  • Nœud Loader (ESP32) : Contrôle du système de chargement 4 tiroirs
  • Nœud Task 3 (ESP32) : Gestion des capteurs NBC
  • Nœud Distance (ESP32) : Capteurs ultrasoniques pour évitement d'obstacles
  • Nœud Moteurs : Contrôleur des 4 moteurs brushless 1000W
  • LattePanda (via dongle CAN) : Ordinateur central exécutant ROS2

Bus CAN secondaire

  • Bras Piper AgileX : Sur son propre bus pour isolation et performance

Architecture logicielle

Système ROS2 sur LattePanda

L'orchestration globale du robot repose sur ROS2 (Robot Operating System 2), framework standard en robotique professionnelle, tournant sur un LattePanda.

Plugin ROS2 pour intégration CAN

Un plugin ROS2 custom a été développé pour faire le pont entre le système ROS2 et tous les nœuds ESP32 du bus CAN. Ce plugin est essentiel au fonctionnement du robot.

Fonctionnalités du plugin

  • Traduction CAN ↔ ROS2 : Convertit les trames CAN en topics/services ROS2
  • Communication bidirectionnelle : Envoi de commandes et réception de telemetry
  • Gestion des priorités : Priorisation des messages critiques (arrêt d'urgence)
  • Diagnostic : Monitoring de l'état de chaque nœud CAN
  • Interface standardisée : API ROS2 classique pour les autres modules

Exemple d'utilisation

Pour déployer le tiroir n°2, un nœud ROS2 publie sur le topic /loader/deploy. Le plugin traduit cette commande en trame CAN vers l'ESP32 du loader, qui exécute l'action et renvoie le statut via CAN, retraduit en topic ROS2 /loader/status.

Système de locomotion

Configuration différentielle

  • 4 moteurs brushless de 1000W avec capteurs Hall pour l'odométrie
  • Contrôleur custom avec double mode de fonctionnement :
    • Mode manuel : Pilotage direct via récepteur ELRS (ExpressLRS)
    • Mode autonome : Commandes depuis ROS2 via CAN Bus
  • Transition fluide entre les modes pour adaptation au terrain

Vision et localisation

Système de vision embarqué

  • Caméra ZED 2i : Vision stéréo pour perception 3D de l'environnement
  • Jetson Nano : Traitement IA temps réel (détection d'obstacles, reconnaissance)
  • Liaison Ethernet : Communication haute vitesse entre Jetson et LattePanda

Navigation et positionnement

  • IMU Ellipse-D (SBG) : Centrale inertielle de grade industriel
  • GNSS RTK : Positionnement centimétrique pour navigation de précision
  • Fusion de données : Combinaison IMU + GNSS + odométrie moteurs

Bras robotique Piper AgileX

Le bras Piper AgileX est intégré au robot pour la manipulation d'objets lors des missions de logistique et de reconnaissance.

Intégration et contrôle

  • Bus CAN dédié : Isolation du bras sur son propre réseau CAN
  • Séquences automatisées : Programmation de mouvements répétitifs (prise/dépose)
  • Mode manuel : Contrôle direct via un jumeau échelle 1/2 pour situations imprévues
